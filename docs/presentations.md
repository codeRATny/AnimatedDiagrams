# Презентации

Анимированную диаграмму можно показывать в PowerPoint, Keynote, Google Slides, LibreOffice Impress и в
веб-презентациях. Экспорт: «Файл → Экспорт» (`Ctrl+E`) → формат **PowerPoint (.pptx)**, CLI
`--export deck.pptx`, MCP `export_animation {format: "pptx"}`.

## Режимы слайдов

| Режим | Что на слайде | Где работает |
|---|---|---|
| **video** (по умолчанию) | MP4 (H.264), запускается сам при показе слайда, один клип повторяется по кругу | PowerPoint, Keynote, LibreOffice Impress |
| **gif** | анимированный GIF | везде, включая Google Slides (видео из .pptx Google Slides не импортирует) |
| **animated** | редактируемые фигуры (узлы, связи, подписи) + анимации PowerPoint: появление/исчезновение, движение пакетов по траекториям, эффекты (пульсация, покачивание, вращение, мигание) | PowerPoint; Impress — частично |
| **morph** | ключевые кадры (по умолчанию каждые 400 мс) отдельными слайдами с переходом «Трансформация» | PowerPoint 2019 / 365; остальные показывают плавную смену слайдов |

Векторные режимы (`animated`, `morph`) рисуют каждый элемент кадра настоящими фигурами DrawingML: цвета,
обводки, пунктир, скругления, свечение и тень, свои SVG-контуры узлов и шрифт дизайн-системы сохраняются;
подписи остаются текстом, их можно править. В режиме редактирования PowerPoint слайд `animated` показывает
все состояния сразу (так выглядят анимированные слайды) — смотрите в режиме показа.

## Пошаговый показ

Маркеры сценария делят анимацию на отрезки: каждый отрезок — отдельный слайд (video/gif/animated) или
группа ключевых кадров (morph), следующий запускается по клику. Отключить: снять «Слайд на каждый отрезок
между маркерами» или `--no-segments`.

## Вставка в существующую презентацию

«Добавить в существующую презентацию» (или `--pptx-insert deck.pptx --pptx-after 3`): слайды добавляются
после указанного слайда (по умолчанию — в конец) на пустом макете этой презентации, её оформление и
остальные слайды не меняются. Результат пишется в выбранный файл (можно указать тот же).

```bash
animated-diagrams --export deck.pptx --pptx-mode video flow.json               # новая презентация 16:9
animated-diagrams --export deck.pptx --pptx-mode animated --slide-size 4:3 flow.json
animated-diagrams --export talk-new.pptx --pptx-insert talk.pptx --pptx-after 5 --pptx-mode morph flow.json
```

## Как это устроено

- Контейнер OPC (zip) — **libzip**, XML-части — **pugixml**; новая презентация строится из шаблона
  python-pptx (MIT, создан в PowerPoint) — его мастер, тема и макеты.
- Видео и GIF рендерятся тем же движком, что и экспорт (libav), и вставляются как медиа с обложкой
  (первый кадр) и автозапуском (`p:timing`, `cMediaNode`).
- Анимации PowerPoint строятся из кадров движка: для сообщений траектория движения — положения пакета по
  времени, состояния узлов и заметки — наложения, которые появляются и исчезают по времени шага.
- Проверка: тесты читают файлы обратно; smoke-тест CI открывает их python-pptx и валидирует слайды по схемам
  ECMA-376 (Transitional); LibreOffice импортирует эффекты, траектории и видео.

## Google Slides

Импортируйте `.pptx` в режиме **gif** — GIF анимируется в Google Slides. Видео можно загрузить на
Google Drive и вставить на слайд вручную (MP4 из режима video или экспорт MP4).

# Локализация

Интерфейс переведён на **английский** (язык исходных строк) и **русский**. Язык выбирается в
«Вид → Язык» (по умолчанию — язык системы, если для него есть перевод, иначе английский) или ключом
`--lang ru` / `--lang en`. Смена языка применяется после перезапуска — приложение предлагает перезапуститься
само, открытые вкладки восстанавливаются.

## Как устроено

| Что | Механизм |
|---|---|
| Строки UI (`UI/`, `apps/`) | `tr("…")` / `QObject::tr("…")` — Qt Linguist |
| Строки ядра (`src/`: подписи каталогов, встроенные элементы, эффекты, анимации, дизайн-системы, пример) | `ad::Tr("context", "…")` и `AD_TR_NOOP("context", "…")` из `Utils/I18n.hpp`; ядро не зависит от Qt — приложение устанавливает переводчик через `ad::SetTranslator()` при старте |
| Стандартные диалоги Qt | `qtbase_<lang>.qm` (пакет `qt6-translations-l10n` / `qt6-qttranslations`, на Windows — рядом с программой) |
| Плагины | словарь `translations` в манифесте (см. ниже) |
| Числа с падежами | `tr("%n frame(s)", nullptr, n)` — формы множественного числа берутся из `.ts` (для русского три формы) |

Файлы переводов — `i18n/animated-diagrams_<код>.ts`; при сборке `lrelease` компилирует их в `.qm` и
вшивает в программу (`:/i18n`). Для сборки нужны Qt LinguistTools: `qt6-l10n-tools` + `qt6-tools-dev`
(Debian/Ubuntu), `qt6-qttools-devel` + `qt6-linguist` (Fedora), на Windows входят в Qt. Без них программа
собирается только с английским интерфейсом (`-DREQUIRE_TRANSLATIONS=ON` превращает это в ошибку — так
собирает CI).

## Обновить переводы после правки строк

```bash
cmake --build build --target update_translations   # lupdate: новые строки появятся в .ts как unfinished
linguist i18n/animated-diagrams_ru.ts                # перевести (или отредактировать XML)
cmake --build build                                  # lrelease + сборка
```

## Добавить язык

1. Добавить `i18n/animated-diagrams_<код>.ts` в `TS_FILES` в `apps/CMakeLists.txt`,
   выполнить `update_translations`, перевести файл в Qt Linguist.
2. Без пересборки: скомпилировать `lrelease animated-diagrams_<код>.ts` и положить `.qm` в папку
   пользовательских переводов («Вид → Язык → Папка переводов…»:
   `~/.local/share/AnimatedDiagrams/animated-diagrams/translations`, `%APPDATA%\…\translations`) или
   в `translations/` рядом с программой. Язык появится в меню автоматически; пользовательский файл
   имеет приоритет над встроенным.

## Переводы в плагинах

Тексты плагина пишутся на английском, переводы — словарём «английский текст → перевод» для каждого языка:

```json
{
  "format": "animated-diagrams-plugin", "id": "com.example.kit", "name": "Messaging kit",
  "elements": [{"id": "broker", "label": "Message broker", "category": "Messaging"}],
  "translations": {
    "ru": {"Messaging kit": "Сообщения", "Message broker": "Брокер сообщений", "Messaging": "Обмен сообщениями"}
  }
}
```

При загрузке подставляются переводы для текущего языка: название и описание плагина, подписи, категории и
описания элементов, эффектов, анимаций и дизайн-систем, роли и подписи/тексты шагов анимаций. Строки без
перевода остаются как есть. Все три плагина в комплекте переведены на русский.

Документы пользователя не переводятся: подписи узлов — это данные. Имена, которые программа подставляет сама
(новый узел «DB 2», пример, категория «Mine»), создаются на текущем языке.

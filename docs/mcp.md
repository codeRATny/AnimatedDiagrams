# MCP-сервер

Animated Diagrams содержит встроенный сервер [Model Context Protocol](https://modelcontextprotocol.io):
AI-агент (Claude Code, Claude Desktop, Cursor, …) может читать и редактировать диаграмму, применять
анимации, импортировать draw.io и Mermaid, рендерить кадры и экспортировать GIF / видео / PowerPoint / Mermaid.

## Подключение

Откройте редактор и включите «Инструменты → MCP-сервер для агентов» или запустите
`animated-diagrams --mcp-port 8765`. С закрытием окна редактора сервер останавливается.
Автономный режим `--mcp` (stdio) удалён. Команды `--export` и `--convert` работают без окна.

```bash
claude mcp add --transport http animated-diagrams http://127.0.0.1:8765/mcp
```

Сервер слушает только `127.0.0.1`, запросы с чужим `Origin` (браузерные страницы) отклоняются.
Порт и автозапуск — в меню «Инструменты». Транспорт — Streamable HTTP без SSE (`POST /mcp`, ответ JSON),
версии протокола `2025-06-18`, `2025-03-26`, `2024-11-05`. `GET /health` — проверка доступности.
## Порядок правок и ревизии

Правки GUI и MCP выполняются в потоке GUI. HTTP-запросы ставятся в очередь по мере получения
полного запроса и обрабатываются по одному. Целевая вкладка фиксируется в момент начала вызова.
Запросы ждут закрытия модального диалога или меню. `export_animation` ждёт фоновую задачу со
снимком документа на момент старта. В это время GUI может продолжать работу, а следующие вызовы
MCP остаются в очереди.

`get_document`, `get_summary`, `select_document`, создание, открытие, импорт и успешные правки возвращают
`structuredContent.revision`. В `list_documents` ревизия указана для каждой вкладки. Это целое число,
действующее только в текущем процессе редактора. Новая вкладка, правка содержимого, замена
документа, undo и redo получают новые значения. Прокрутка, масштаб, выбор элементов и сохранение
файла не меняют ревизию.

Передайте возвращённую ревизию как `expectedRevision` при правке существующего документа. Если
значение разошлось, MCP возвращает `isError: true`, `structuredContent.code: "revision_conflict"`
и актуальную `structuredContent.revision`. Повторно прочитайте документ и пересчитайте правку
перед новым вызовом. Без `expectedRevision` правка применяется к актуальному состоянию вкладки
в порядке очереди. Ошибка правки оставляет содержимое, ревизию и историю отмены без изменений.
Параметр не применяется к созданию вкладок, чтению, сохранению и экспорту.

## Сессии агентов

`register_agent` возвращает `agentId` и привязывает агента к текущей вкладке. Передавайте этот ID
в аргументах каждого последующего вызова от имени агента. Вызовы без `agentId` продолжают работать
с вкладкой, активной на момент начала вызова. Ошибочный, просроченный или отозванный ID приводит к
ошибке до выполнения инструмента. Для `unregister_agent` ID обязателен.

Чтобы сменить привязку, передайте `agentId` и `index` из свежего ответа `list_documents` в
`select_document`. Переключение вкладки пользователем и смена порядка вкладок не меняют привязку.
Создание, открытие и импорт документа через MCP привязывают агента к новой вкладке. Подтверждённое
закрытие вкладки отрегистрирует всех её агентов.

Сессия заканчивается после `unregister_agent`, остановки MCP-сервера или 15 минут без вызовов с её
`agentId`. Завершение отдельного HTTP-запроса не завершает сессию.

На холсте отображается цветной курсор агента с его ID. Узлы, рёбра и шаги с привязкой к
холсту задают позицию курсора. Через 30 секунд без вызовов курсор скрывается, а следующий вызов
с действительным ID возвращает его. Длительность перемещения по холсту задаёт параметр
`agentCursorMoveMs` секции `[mcp]` в настройках редактора. По умолчанию это 180 мс, допустимый
диапазон — от 1 до 5000 мс. Новые вкладки считывают параметр при открытии.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `register_agent` | выдать уникальный в пределах процесса идентификатор `agentId`; аргументы не требуются |
| `unregister_agent` | немедленно завершить сессию с указанным `agentId` |
| `get_summary` | обзор: узлы с id, связи, шаги, маркеры и сегменты, библиотека — вызывать первым |
| `get_document` | содержимое документа и его текущая ревизия |
| `list_documents`, `select_document` | открытые вкладки и выбор документа агента или активной вкладки |
| `list_library` | типы элементов, эффекты, анимации, дизайн-системы и справочники (формы, состояния, варианты сообщений) |
| `new_document`, `open_document`, `save_document` | файлы |
| `import_drawio` | импорт страницы draw.io (`path` или содержимое `xml`) |
| `import_mermaid` | импорт Mermaid (`text` или `path`): flowchart → узлы и связи, sequenceDiagram → анимированный сценарий ([подробнее](mermaid.md)) |
| `to_mermaid` | документ как текст Mermaid (`kind`: flowchart / sequence / markdown), без записи файла |
| `add_node`, `update_node`, `remove_node` | узлы (`style` сливается, `null` удаляет поле) |
| `add_edge`, `update_edge`, `remove_edge` | связи |
| `add_step`, `update_step`, `remove_step` | шаги сценария |
| `apply_animation` | вставить шаблон анимации, сопоставив роли узлам |
| `add_marker`, `update_marker`, `remove_marker` | маркеры (главы) таймлайна: `add_marker {time, label}` → `id`; `update_marker {id, time?, label?}` |
| `upsert_library_item`, `remove_library_item` | свои элементы / эффекты / анимации / дизайн-системы в документе |
| `set_scene` | название, длительность, цвета холста, дизайн-система (`designSystem`) |
| `auto_layout` | авто-раскладка узлов по связям |
| `render_frame` | PNG кадра в момент `timeMs` — визуальная проверка |
| `export_animation` | экспорт GIF / PNG / WebM / MP4 (libav, `quality` 0..4); PowerPoint: `format: "pptx"`, `pptxMode` video / gif / animated / morph, `slideSize`, `insertInto` + `insertAfter` (добавить в существующую презентацию), `bySegments`; `html` — интерактивный HTML-плеер (`loop`, `autoplay`; если сборка включает плеер); `mermaid` — текст Mermaid (`mermaidKind`). [Подробнее](presentations.md) |
| `undo`, `redo` | история |

Ошибки аргументов возвращаются как результат с `isError: true` и понятным текстом.
Сценарий работы агента описан в скилле [`skills/animated-diagrams`](../skills/animated-diagrams/SKILL.md).

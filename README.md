# Animated Diagrams

Специализированный редактор для создания диаграмм архитектуры и **анимации flow-сценариев**:
запросы между сервисами, недоступность, таймеры/таймауты, ретраи, параллельные действия,
fallback-переключения — всё это можно нарисовать и проиграть по времени.

> В комплекте предзагружен пример: `Сервис A → B (недоступен) → таймаут 5с + ретраи → fallback на C → 200 OK`.

---

## Запуск

Ядро приложения — чистый HTML/JS/SVG, сборка не нужна. Есть два способа запуска.

### Десктоп-приложение (Electron) — рекомендуется

```bash
npm install     # один раз: ставит Electron
npm start       # запуск десктоп-приложения
```

Окно десктоп-версии **без системной рамки** — используется собственный **кастомный хедер в стиле
приложения** (не системное меню): слева меню **Файл / Правка / Вид / Справка** с выпадающими списками,
по центру имя диаграммы, справа кнопки управления окном (свернуть / развернуть / закрыть). Доступны
нативные диалоги **Открыть…/Сохранить JSON…**, сохранение **GIF/WebM** через системный диалог; имя
диаграммы меняется через **Файл → Переименовать…** или двойным кликом по названию в хедере. Горячие
клавиши: `Ctrl/Cmd+N` — новая, `Ctrl/Cmd+O` — открыть, `Ctrl/Cmd+S` — сохранить, `Ctrl/Cmd+E` —
экспорт GIF/видео, `F11` — полный экран.

> **Linux с отключёнными user-namespaces** (некоторые серверы/контейнеры): если при `npm start`
> появляется ошибка про `chrome-sandbox`, запускайте `npm run start:nosandbox`.
> На обычном рабочем столе (Linux/Windows/macOS) достаточно `npm start`.

**Сборка установщиков** (AppImage/deb/rpm, exe, dmg) — через `electron-builder`:

```bash
npm run dist          # для текущей ОС
npm run pack:linux    # AppImage + deb + rpm
npm run pack:win      # Windows NSIS (.exe)
npm run pack:mac      # macOS dmg
```

Готовые пакеты появятся в папке `release/`. Для кросс-сборки под все ОС из одного окружения
используйте CI/CD (см. ниже) — там сборка идёт в Docker-образе с wine.

### В браузере (без установки)

Откройте `index.html` двойным кликом, либо (если браузер ограничивает `file://`) поднимите статический сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

Проект сохраняется автоматически в `localStorage`. Для переноса — меню **Файл → Сохранить JSON**.
(Файл `js/electron-bridge.js` в браузере бездействует — включается только внутри Electron.)

## CI/CD (GitHub Actions)

Сборка установщиков автоматизирована через GitHub Actions и Docker.

- **`Dockerfile`** — образ со всеми библиотеками для сборки: Node + **wine** (для `.exe`/NSIS) +
  инструменты Linux-пакетов (`dpkg`/`fakeroot` для `.deb`) + **rpm** (для `.rpm`). База —
  `electronuserland/builder:wine`.
- **`.github/workflows/build.yml`** — на `push` в `main`, на теги `v*` и вручную (`workflow_dispatch`):
  1. собирает Docker-образ из `Dockerfile`;
  2. этим образом запускает `electron-builder` и собирает **deb, rpm и exe**;
  3. выкладывает установщики в артефакт **`installers`** (скачивается со страницы запуска workflow).

Иконка приложения — `build/icon.png` (512×512).

Локально тот же результат можно получить так (контейнер запускается **от текущего пользователя**
`-u $(id -u):$(id -g)`, иначе `npm ci` внутри создаст файлы от root и сломает права на `node_modules`):

```bash
docker build -t ad-builder .
docker run --rm -u "$(id -u):$(id -g)" -e HOME=/tmp \
  -v "$PWD":/project -w /project ad-builder \
  bash -lc "npm ci && npx electron-builder --linux deb rpm --win nsis"
```

> Если права на `node_modules` уже испортились (ошибка `EACCES` от npm), верните владельца:
> `docker run --rm -v "$PWD":/project alpine chown -R $(id -u):$(id -g) /project/node_modules`,
> затем `npm ci`.

## Как пользоваться

### 1. Рисуем диаграмму
- **＋ Узел** (или клавиша `N`) + выбранный тип слева (Сервис / Клиент / Шлюз / БД / Очередь / Внешний) → клик по холсту.
- **↗ Связь** (`E`) → клик по первому узлу, затем по второму — появится стрелка. Между парой узлов можно
  создавать **несколько связей** (они автоматически расходятся дугами).
- **▘ Выбор** (`V`) → перетаскивание узлов, выделение. Двойной клик по узлу — переименовать.
- У узла в свойствах можно задать **Подзаголовок** — надпись под именем. Если он не задан, показывается
  текущий статус узла (по умолчанию «Норма»); во время анимации при смене состояния всегда виден статус.
- Колесо мыши — зум, перетаскивание пустого места или `Пробел`+drag — панорамирование.
- Панель **Свойства** справа — редактирование выбранного узла/связи.

**Связи — ручное позиционирование и настройки:**
- **Точки изгиба:** двойной клик по связи добавляет точку изгиба, двойной клик по точке — удаляет; точки
  перетаскиваются. Связь плавно проходит через них.
- **Точки соединения (порты):** в свойствах узла — **＋ Добавить точку соединения**; точки-кружки
  перетаскиваются по узлу. В режиме **Связь** кликните по точке (а не по узлу), чтобы привязать связь именно к ней.
- **Двунаправленная связь:** галочка в свойствах связи — стрелки появляются с обеих сторон.
- **Изгиб / стиль / направление** также настраиваются в свойствах связи.

### 2. Строим сценарий анимации (нижняя панель — таймлайн)
Сценарий — это набор **шагов**, каждый со своим **началом** и **длительностью**.
Выберите тип шага, нажмите **＋ Добавить шаг**, затем настройте его в **Свойствах**.

Типы шагов:

| Тип | Что делает |
|-----|-----------|
| **Сообщение** | Пакет летит **по выбранной связи** (учитываются её изгибы, точки и порты), в прямом или обратном направлении. Варианты: запрос, ответ, ретрай, ошибка, успех, событие. Если связь не выбрана — летит по прямой между узлами. |
| **Таймер** | Кольцо обратного отсчёта на узле с выбором единицы отображения (секунды/минуты/часы/дни), например таймаут «5 мин». Значение считается вниз до нуля за время анимации. |
| **Смена состояния** | Узел меняет состояние/цвет. Есть пресеты (норма, активен, занят, предупреждение, **недоступен**, успех), а подпись, цвет-акцент и размер шрифта можно переопределить своими. |
| **Действие** | Показывает действие на выбранном сервисе — бейдж с текстом (напр. «Обработка», «Запись в БД») и вращающимся спиннером под узлом + подсветка узла. |
| **Соединение** | Действие над связью между сервисами: своя **надпись** (напр. «Разрыв», «Установление»), **цвет** и **анимация линии** (бегущий пунктир / пунктир / сплошная / пульсация). Положение надписи вдоль связи, смещение и размер шрифта настраиваются. |
| **Заметка** | Текстовая подпись на холсте в заданный момент. |
| **Пульс** | Подсветка/пульсация узла, чтобы привлечь внимание. |

**Тайминг = поведение:**
- Блоки на таймлайне можно **тащить** (менять начало) и **растягивать за края** (менять длительность).
- **Параллельность** — просто перекрывающиеся во времени блоки (таймер + ретраи идут одновременно).
- **Последовательность** — блоки друг за другом.
- Клик по линейке времени сверху — перемотка (scrub).
- **Ctrl + колесо мыши** над таймлайном — масштабирование шкалы времени (с привязкой к позиции курсора);
  деления линейки подстраиваются под масштаб.

### 3. Проигрываем
Кнопки внизу слева: `⏮ ▶/⏸ ⏹ ⏭`, выбор скорости (0.25×–4×), длительность сцены, повтор.
`Пробел` — играть/пауза.

### 4. Экспортируем анимацию (GIF / WebM)
Кнопка **◉ GIF / Видео** в верхней панели открывает диалог экспорта:

- **Формат:** **GIF** (универсально, зацикленно — для документации, чатов, задач) или
  **WebM** (лучше качество и меньше размер, особенно для длинных сценариев).
- **Частота кадров** (8–60 fps), **масштаб/разрешение** (1×–10×; кадр ограничен 12000px по большей стороне).
  При больших масштабе/длительности показывается предупреждение об объёме — для тяжёлых случаев берите WebM.
- **Кадрирование:** «По содержимому» (аккуратно обрезает по диаграмме, независимо от текущего
  зума/прокрутки) или «Как на экране» (текущая видимая область).
- **Фон:** любой цвет (по умолчанию тёмный; быстрые кнопки тёмный/белый).
- **Зациклить** — для GIF.

Экспорт детерминированный: каждый кадр берётся из движка как функция от времени, поэтому
результат точно совпадает с проигрыванием. Готовый файл автоматически скачивается.

> GIF всё детерминированно рисуется в браузере (энкодер `gifenc`, без сети и без web-workers,
> работает и из `file://`). WebM пишется встроенным `MediaRecorder` в реальном времени.
> Для длинного сценария при высоком FPS GIF может выйти крупным — тогда берите WebM или уменьшите FPS.

## Модель состояний узла

Состояние действует **в пределах своего блока** `[начало, начало+длительность)`.
Если на узле активны несколько блоков — побеждает начавшийся позже. Вне блоков — состояние
по умолчанию «Норма». Чтобы состояние держалось до конца сцены — просто растяните его блок.

## Формат проекта (JSON)

```jsonc
{
  "nodes":  [ { "id", "label", "subtitle", "kind", "x", "y", "w", "h", "color", "shape",
                "ports": [ { "id", "dx", "dy" } ] } ],             // dx/dy — смещение точки от угла узла
  "edges":  [ { "id", "from", "to", "label", "style", "curve",
                "fromPort", "toPort",           // id портов узлов (или null — авто)
                "waypoints": [ { "x", "y" } ],  // точки изгиба
                "bidirectional": false } ],
  "scenario": {
    "duration": 12000,          // мс
    "steps": [
      { "type": "message", "from", "to", "edgeId", "variant", "label", "start", "duration" }, // edgeId — по какой связи
      { "type": "timer",   "nodeId", "seconds", "unit", "label", "start", "duration" }, // unit: s|m|h|d
      { "type": "state",   "nodeId", "state", "start", "duration" },
      { "type": "note",    "text", "x", "y", "color", "start", "duration" },
      { "type": "pulse",   "nodeId", "color", "start", "duration" }
    ]
  }
}
```

Импорт/экспорт этого JSON — кнопки в верхней панели.

## Deep-link (удобно для демо)

К адресу можно добавить параметры:
- `?t=5000` — открыть на кадре 5.0 с;
- `?play=1` — сразу запустить воспроизведение;
- `?export=gif` (или `?export=webm`) — сразу открыть диалог экспорта.

Пример: `index.html?t=5000&play=1`.

## Структура кода

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка UI |
| `css/styles.css` | Тёмная тема редактора |
| `js/store.js` | Модель данных, персистентность, каталоги типов, пример flow |
| `js/geometry.js` | Вся геометрия связей (`AD.geom`): пути строит d3, спец-математика — отдельными функциями |
| `js/vendor/d3.min.js` | d3 v7 (d3-scale для шкалы времени, d3-shape/d3-path для кривых связей) |
| `js/diagram.js` | Отрисовка и редактирование диаграммы (SVG); геометрия — через `AD.geom` |
| `js/engine.js` | Детерминированный движок воспроизведения (всё — функция от времени `t`) |
| `js/timeline.js` | Редактор сценария: таймлайн, drag/resize блоков, перемотка |
| `js/export-media.js` | Экспорт в GIF/WebM: захват кадров, растр SVG→canvas, кодирование |
| `js/vendor/gifenc.umd.js` | GIF-энкодер (gifenc, MIT), обёрнут в глобал для classic-script |
| `js/app.js` | Сборка UI: инспектор, транспорт, действия хедера, горячие клавиши |
| `js/menu.js` | Кастомный хедер-меню (Файл/Правка/Вид/Справка) + управление окном |
| `js/electron-bridge.js` | Интеграция с Electron (нативные диалоги); в браузере бездействует |
| `electron/main.js` | Главный процесс Electron: фреймлесс-окно, IPC файловых диалогов и управления окном |
| `electron/preload.js` | Безопасный мост (contextIsolation): выставляет `window.electronAPI` |
| `package.json` | Зависимости и скрипты Electron / electron-builder |
| `Dockerfile` | Образ для сборки установщиков (node + wine + dpkg + rpm) |
| `.github/workflows/build.yml` | CI: сборка deb/rpm/exe в Docker → артефакты |
| `build/icon.png` | Иконка приложения (512×512) |

### Горячие клавиши
`V` выбор · `N` узел · `E` связь · `Del/Backspace` удалить · `Пробел` play/pause · `Esc` снять выделение.
